# DAN-MMGradCAM — Module 3 HPC Package (s9534)

This package was prepared using the uploaded `Dan-mmgradcam.zip` (17 November 2026). It **does not** contain original CNN checkpoints, ECG signals, or untrusted `checkpoint.pkl` data. It **never** reruns the 30 Module 2 perturbations.

## What was verified in the supplied ZIP

- Full folder: `Dan-mmgradcam/module2_full_v2_s9534/` (not the `module2_smoke8` folder).
- 1,054 Module 2 records, 30 perturbations, 600 temporal columns.
- `run_metadata.json`: reported original scaler with 9,534 fit records and TensorFlow 2.21.0. This claim is from its metadata; the ZIP contains no scaler itself.
- `noise_stability_maps.npz` contains `mu1`, `mu2`, `S1`, `S2`, `H1j`, `H2j`, `R`, `base1`, `base2`, IDs and valid masks.
- Numerically `R = sqrt(H1j * H2j)` on valid positions.
- Across all 1,054 records, 939 have both original predictions correct and 752 of those accept all 30 perturbations jointly. **These are not the frozen Module 1 primary-cohort counts**. The script computes primary-cohort counts on HPC and never assumes old 694/554 counts.
- 2D input is still generated by the Module 2 rerenderer, and 2D projection is on-trace. These are not identical to the original-image/G12 Module 1 experiment.

## Exact scientific definitions

**Module 3A (original):** `R(u) = sqrt(H1j(u)*H2j(u))` with `Hbj=mu_b_joint*S_b_joint` using jointly accepted perturbations. The file `R` is reused unchanged.

**Controlled no-stability ablation:** `F_mu(u) = sqrt(mu1(u)*mu2(u))`. *Only calculated for records with 30/30 clean joint acceptance* so branch-wise and joint acceptance sets are identical. Outside this subset, the ZIP does not contain the original raw maps necessary to construct the matched joint mean.

**Original-map fusion:** `F_base(u) = sqrt(base1(u)*base2(u))` using Module 2 baseline maps, not Module 1 G12.

**Module 3B (new, optional):** Use baseline native 2D spatial Grad-CAM from the **same Module 2 rerendered CNN**, form a temporal per-column fraction of spatial CAM mass in the ±6-pixel ECG trace corridor,

`F_trace(u) = sum_y H2D(y,u)*M(y,u) / (sum_y H2D(y,u) + eps)`.

Then `R_trace(u) = R(u) * F_trace(u)^lambda`; evaluate lambda = 0.5, 1.0, 2.0 as pre-specified sensitivity settings. This F_trace uses **unperturbed** spatial Grad-CAM as a support heuristic; it is **not** a perturbation-derived stability estimate. There is no peak rescaling, so intensity remains faithful to R and F_trace.

Do **not** use `combined_R_D_maps.npz`'s A/D as F_trace without validating their definitions. Do **not** substitute Module 1 spatial CAM in Module 3B's primary matched-pipeline comparison; if studied, label it a separate cross-pipeline sensitivity analysis.

Run these commands on the **Mac**, not inside SSH. If the original data ZIP has a different path on your Mac, replace it.

## 2 — HPC: install the scripts and run stage 1 (CPU, no model inference)

```bash
ssh g202527350@hpcmaster-1.kfupm.edu.sa
mkdir -p ~/mm_gradcam/module3_aligned/{inputs,outputs,logs,scripts}
unzip -oq ~/mm_gradcam/module3_sources/Module3_HPC_Aligned_Package.zip \
    -d ~/mm_gradcam/module3_aligned/

bash ~/mm_gradcam/module3_aligned/scripts/run_stage1.sh \
    ~/mm_gradcam/module3_sources/Dan-mmgradcam.zip

cat ~/mm_gradcam/module3_aligned/outputs/module3a_v1/module3a_summary.json
```

The extractor selectively copies six `.npy/.npz`/CSV/JSON data files from **full** s9534, skips pickled checkpoints, creates SHA256 manifest, and refuses silent replacement with different source files. The Module 3A preparer checks Module 1 ID, label and valid masks, the saved R formula, and produces:

- `outputs/module3a_v1/module3a_maps.npz`: eligible primary maps `R`, `Fbase`, `Fmu_matched30` (NaN for non-matched records), `S1`,`S2`, etc.
- `module3a_record_audit.csv` and `module3a_summary.json` with the **new** eligible counts.
- `module3a_matched30_records.csv` for clean controlled ablation.
- `ECG_209_module3a.png`, if ECG 209 remains eligible (temporal attribution grid, not a redrawn ECG).

**STOP if the audit fails.** Fix identifiers/masks/model definition rather than skipping records until the numbers match expectations.

Outputs: `module3b_maps.npz`, `module3b_record_metrics.csv`, `module3b_summary.json`, and `ECG_209_module3b.png`. No invented CAM values and no display-only re-normalization.

**If the 2D CAM gate fails:** The original Module 2 source code may have changed between the old GitHub `Module2` branch and s9534 new run. Obtain the updated `module2_common.py` from teammate and use that version (without changing original Module 1) before retrying. Do not weaken QC solely to obtain a result.

## 5 — Full Module 3B cohort, only after pilot passes

Use `m3b_generate_trace_support.py --start 0 --limit 50 --out ...chunk_0000.npz`, then start 50, 100, etc. in separate compute jobs. Each chunk must use a unique output filename, and `m3b_apply.py --trace-npz chunk_*.npz` accepts multiple chunks. Do not submit the full cohort before confirming baseline and CAM reproduction on pilot and a class-diverse subsample.

## 6 — Faithfulness and final validation

The stage 1+2 scripts establish **R and R_trace maps**, not faithfulness. For final Module 3, use the existing Module 3A deletion evaluator with the **new `inputs/module2_s9534` folder**, verify original 1D and 2D prediction vectors, and compare `OriginalFusion`, `NoStability`, and `Module3A_R` on *matched30* records, with random controls and paired CIs. Then extend its map menu to accept `Rtrace_lambda_*` from `module3b_maps.npz` and evaluate those maps **on exactly the same ECGs, deletion budgets, CNNs and renderer**. The old faithfulness results from a different scaler must not be reused as s9534 results.

Additional checks: compare block sizes (25/50/100), randomization/sanity controls, sensitivity across lambda, class breakdown, and report failure of original-image vs rerendered 2D equivalence as a limitation. Save logs, code version, experiment config, and checkpoint SHA256 for reproducibility.
